Devin Prompts

Pre-Completed Session Prompt

Run 2-3 hours before the demo. This creates Session B.

Migrate this Angular 14 digital banking frontend to Angular 17.

Repo: https://github.com/gaurav21/bofa-digital-banking-frontend

## Migration Scope

### 1. Angular 14 → 17 Core
- Update all @angular/* packages from ^14.1.0 to ^17.x
- Update @angular/material and @angular/cdk from ^14.1.0 to ^17.x
- Update rxjs from ~7.5.0 to ~7.8.x
- Update zone.js from ~0.11.4 to ~0.14.x
- Update TypeScript to version compatible with Angular 17

### 2. NgModules → Standalone Components
Convert ALL modules to standalone components:
- AppModule (app.module.ts) → standalone bootstrap in main.ts
- CoreModule → providedIn: 'root' services
- SharedModule → remove, export standalone components
- AccountsModule → standalone AccountsDashboardComponent with lazy route
- TransfersModule → standalone TransferFormComponent with lazy route
- BeforeLoginModule → standalone BeforeLoginComponent with lazy route
- AfterLoginModule → standalone AfterLoginComponent with lazy route
- BofaAccountCardModule → standalone BofaAccountCardComponent
- BofaNavHeaderModule → standalone BofaNavHeaderComponent
- BofaTransactionTableModule → standalone BofaTransactionTableComponent

For each: add standalone: true, add imports: [...], remove the .module.ts file.

### 3. Angular Material Legacy → Modern
- Replace ALL MatLegacy* imports with Mat*
- Update paths from @angular/material/legacy-* to @angular/material/*
- Update template selectors

### 4. Routing Updates
- Convert app-routing.module.ts to standalone routes with provideRouter()
- Use loadComponent() for lazy routes
- Update auth.guard.ts to functional guard pattern

### 5. Build & Test
- Run ng build --configuration production — must pass zero errors
- Run ng test (Jest) — fix any failing tests
- Run ng serve and verify app loads in browser

### 6. Frontend Visual Testing
After migration builds:
- Start dev server with ng serve
- Open http://localhost:4200
- Navigate and verify: login page renders, accounts dashboard loads with cards, transaction table renders, transfer form works, navigation header works across pages
- Note any visual issues

### 7. PR Description
Create detailed PR: changes by category, files modified with rationale, breaking changes, low-confidence areas flagged, test results.
