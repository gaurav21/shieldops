Appendix · Cloud Migration

Devin accelerates code transformation — after your architects set the target

Cloud migration is re-architecture work that requires human judgment on the target design. Devin accelerates the code-level transformation once the architectural decisions are made, and flags low-confidence areas for human review.

☁️ What Devin Accelerates

Code transformation, not architecture decisions

  • IBM MQ → SQS FIFO — MessageGroupId mapping, DLQ patterns (given target design)
  • Oracle → Aurora PostgreSQL — SQL dialect conversion, stored procedure migration
  • LDAP → Cognito — group mapping, RBAC code changes
  • Spring DI → Lambda handlers — stateless extraction per architect spec

Low-confidence transformations are flagged for human review — Devin does not auto-merge architectural decisions.

⚠️ What Stays Human

Architecture and design require judgment

  • Target architecture selection (Lambda vs ECS vs Fargate)
  • Data residency and compliance boundary decisions
  • Message ordering and SLA trade-off analysis
  • Dual-run / canary deployment strategy
  • Cross-service integration contract changes

Appendix · Security & Architecture

Built for regulated financial services

Every design decision assumes a hostile network and a compliance audit.

Infrastructure Isolation

Each agent = its own VM

  • In-your-VPC deployment option — code never leaves your network
  • Each Devin session runs in its own isolated VM — not shared-kernel containers
  • Code is cloned in, work is done, PR is pushed. No data persists beyond the session
  • VPC peering, self-hosted, and air-gapped options available
Compliance & Audit

SOC 2 Type II certified

  • SOC 2 Type II — independently audited security controls
  • Code never used for training — your code is your code
  • SAML SSO / SCIM — enterprise identity integration
  • RBAC — granular role-based access control
  • Full audit trail — every action logged and traceable
Human Oversight

Every change = a human-approved PR

  • Never auto-merges to prod — every Devin output is a PR for human review
  • Auto-Triage is network-sandboxed — prompt-injection and exfiltration protection
  • Pause & take over — jump into any session at any time
  • Session-level RBAC — control who can trigger, review, and approve
